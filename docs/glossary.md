# Glossary

| Term | Meaning |
|---|---|
| 5GC | 5G Core network |
| 5G-AKA | 5G Authentication and Key Agreement, the default authentication method |
| AES | Advanced Encryption Standard |
| AKA | Authentication and Key Agreement |
| AMF | Access and Mobility Management Function |
| ANSI X9.63 | Key derivation function standard used by ECIES |
| AUSF | Authentication Server Function |
| BCD | Binary-Coded Decimal, two digits per byte |
| BSF | Binding Support Function |
| CTR | Counter mode, a block cipher mode |
| DEM | Data Encapsulation Mechanism, the symmetric part of a hybrid scheme |
| ECDH | Elliptic Curve Diffie-Hellman |
| ECIES | Elliptic Curve Integrated Encryption Scheme |
| FIPS | Federal Information Processing Standard |
| gNB | 5G base station |
| GTP-U | GPRS Tunnelling Protocol, user plane |
| HMAC | Hash-based Message Authentication Code |
| ICB | Initial Counter Block |
| IMSI | International Mobile Subscriber Identity |
| KDF | Key Derivation Function |
| KEM | Key Encapsulation Mechanism |
| MAC | Message Authentication Code |
| MCC | Mobile Country Code |
| ML-KEM | Module-Lattice-based Key Encapsulation Mechanism (FIPS 203) |
| MNC | Mobile Network Code |
| MSIN | Mobile Subscription Identification Number |
| N1, N2, N3, N4 | Reference points: UE-AMF, gNB-AMF, gNB-UPF, SMF-UPF |
| NAS | Non-Access Stratum |
| NF | Network Function |
| NGAP | NG Application Protocol (N2) |
| NR | New Radio, the 5G radio technology |
| NRF | Network Repository Function |
| NSSF | Network Slice Selection Function |
| OPc | Operator variant key derived from OP, used in authentication |
| PCF | Policy Control Function |
| PDU | Protocol Data Unit (a PDU session is a data connection) |
| PFCP | Packet Forwarding Control Protocol (N4) |
| PKI | Public Key Infrastructure |
| PRB | Physical Resource Block |
| RRC | Radio Resource Control |
| SA | Standalone (5G core without 4G) |
| SBI | Service-Based Interface |
| SCP | Service Communication Proxy |
| SCTP | Stream Control Transmission Protocol |
| SIDF | Subscription Identifier De-concealing Function |
| SMF | Session Management Function |
| SUCI | Subscription Concealed Identifier |
| SUPI | Subscription Permanent Identifier |
| TUN | Virtual network interface in the Linux kernel |
| UDM | Unified Data Management |
| UDR | Unified Data Repository |
| UE | User Equipment (the phone) |
| UPF | User Plane Function |
| USIM | Universal Subscriber Identity Module |
